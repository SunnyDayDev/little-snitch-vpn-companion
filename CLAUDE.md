# Claude Code

Общие правила проекта — в `AGENTS.md` выше. Здесь только то, чего у остальных
агентов нет.

## Слэш-команды

Шаги openspec-процесса вызываются командами из `.claude/commands/opsx/`:
`/opsx:propose`, `/opsx:apply`, `/opsx:sync`, `/opsx:archive`, а также
`/opsx:explore` и `/opsx:update`. Другим агентам те же сценарии доступны
одноимёнными навыками, поэтому команды остаются только здесь и в `.agents/`
не дублируются.

## Навыки

`.claude/skills/<name>` — относительные симлинки на `.agents/skills/<name>`,
по одному на навык. Симлинк на `.claude/skills` целиком не ставить: у Claude Code
были регрессии с обнаружением навыков через симлинкнутую директорию верхнего
уровня, а ссылка на каждый навык по отдельности — официально поддержанный вариант.
