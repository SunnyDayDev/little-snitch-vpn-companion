# Spec Delta

## MODIFIED Requirements

### Requirement: Иконка отражает состояние

Иконка строки меню SHALL отражать сводное состояние — худшее среди включённых детекторов в порядке Leak > Checking > Offline > Protected; при паузе мониторинга — Paused; без включённых детекторов — Offline. Иконка SHALL быть template-щитом, меняющимся по сводному состоянию, с цветовым акцентом по семантике: Protected — `checkmark.shield`, монохром; Leak — `exclamationmark.shield`, danger-акцент; Offline — `shield.slash`: монохром, если ни один детектор в Offline не строгий, warn-акцент, если хотя бы один из них строгий (трафик по его пути закрыт); Checking — щит с индикатором проверки (ближайший SF Symbol), warn-акцент; Paused — `shield.lefthalf.filled` (замена `minus.shield`), warn-акцент. Допустима замена ближайшими SF Symbols.

#### Scenario: Переход в Leak

- **WHEN** любой включённый детектор перешёл в Leak, остальные защищены
- **THEN** иконка меняется на щит с восклицательным знаком и danger-акцентом

#### Scenario: Закрыто без утечки видно с одного взгляда

- **WHEN** один из детекторов строгий и в Offline или Checking, остальные защищены
- **THEN** иконка получает warn-акцент, отличимый и от монохромного Protected, и от danger-Leak

#### Scenario: Все защищены

- **WHEN** все включённые детекторы в Protected
- **THEN** иконка — монохромный щит с галкой

### Requirement: Состав поповера

Поповер (ширина 340 pt) SHALL содержать сверху вниз: шапку статуса (иконка 26 pt, заголовок по сводному состоянию «Защищено»/«Утечка»/«Офлайн»/«Проверка»/«Пауза»; когда сводное состояние хуже Protected, заголовок SHALL называть детектор-виновника, например «Утечка: Через резидентный прокси»; подзаголовок с контекстом его состояния); баннер состояния детектора-виновника; блок «Детекторы» — по строке на каждый детектор: иконка состояния, имя, состояние с egress (у выключенного — «выключен»); инфо-строки «Проверка» (давность последней пробы + активные слои), «Группы LS» (фактически включённые группы по арбитражу; danger-цвет при Leak любого детектора, warn-цвет при «включены без утечки»), «Сеть» (тип + шлюз); действия «Проверить сейчас» (проба всех включённых детекторов), «Пауза мониторинга»/«Возобновить», «Журнал…», «Настройки…»; пункт «Завершить» с шорткатом ⌘Q.

Баннеры SHALL зависеть от состояния и режима детектора-виновника: все Protected — зелёный «Все пути работают» (при одном детекторе — «Цепочка работает»); Leak — красный с именем детектора и фактическим составом включённых им групп; Checking (строгий) — warn «Закрыто — ждём подтверждения VPN» с именем детектора и составом включённых групп; Offline в строгом режиме — warn «Закрыто: сети нет»; Offline и Paused без строгих детекторов — без баннера, подзаголовок «состояние групп не меняется». Paused при наличии строгих детекторов — warn-баннер «Пауза: трафик закрыт». Под `observeOnly` утверждения «трафик закрыт» SHALL NOT показываться (группы не тронуты — ФТ-10 побеждает). Без включённых детекторов шапка SHALL сообщать «Детекторов нет» с подсказкой открыть настройки.

#### Scenario: Поповер при Protected

- **WHEN** пользователь открывает поповер, когда все включённые детекторы в Protected
- **THEN** отображается зелёный баннер, блок детекторов с состоянием и egress каждого и инфо-строка «Группы LS: выключены»

#### Scenario: Поповер при Leak

- **WHEN** детектор «Через резидентный прокси» в Leak, остальные защищены
- **THEN** заголовок «Утечка: Через резидентный прокси», подзаголовок с его egress и диагнозом, красный баннер с перечислением включённых им групп, в блоке детекторов его строка danger-цветом, «Группы LS» перечисляет включённые группы

#### Scenario: Поповер при Checking в строгом режиме

- **WHEN** строгий детектор в Checking после смены сети, остальные защищены
- **THEN** заголовок «Проверка: <имя>», warn-баннер «Закрыто — ждём подтверждения VPN» и инфо-строка «Группы LS: включены …» warn-цветом

#### Scenario: Поповер при Offline в реактивном режиме

- **WHEN** единственный детектор реактивный, сети нет и пользователь открывает поповер
- **THEN** заголовок «Офлайн», баннера нет, подзаголовок объясняет, что состояние групп не меняется

#### Scenario: Выключенный детектор в блоке

- **WHEN** один из детекторов выключен
- **THEN** его строка в блоке детекторов показана приглушённо с состоянием «выключен», в сводное состояние он не входит

#### Scenario: Проверить сейчас

- **WHEN** пользователь нажимает «Проверить сейчас»
- **THEN** немедленно выполняется свежая проба каждого включённого детектора и UI обновляется по их результатам

#### Scenario: Пауза и возобновление из поповера

- **WHEN** пользователь нажимает «Пауза мониторинга»
- **THEN** все детекторы переходят в Paused (строгие — с предварительным закрывающим reconcile), пункт меняется на «Возобновить»
