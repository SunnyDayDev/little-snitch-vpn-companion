# Spec Delta

## MODIFIED Requirements

### Requirement: Состав записи журнала

Каждое событие SHALL записываться в журнал с полями: время; триггер (растяжка / путь / проба / ру-маяк / helper / пользователь / питание); детектор (имя, если событие относится к одному детектору: проба, обрыв его растяжки, переход его состояния, изменение его настроек; события общих слоёв и helper — без детектора); egress-IP (если известен); событие (переход состояний или факт); действие (что сделано с группами). Записи без поля «детектор» от прежних версий SHALL читаться как есть. В окне журнала имя детектора SHALL показываться префиксом перед текстом события.

#### Scenario: Запись перехода в Leak

- **WHEN** зафиксирован переход Protected → Leak детектора «Через резидентный прокси» по плановой пробе
- **THEN** в журнал пишется запись с временем, триггером «проба», детектором «Через резидентный прокси», egress-IP, событием перехода и списком включённых групп

#### Scenario: Запись по событию питания

- **WHEN** зафиксировано засыпание или пробуждение машины
- **THEN** в журнал пишется запись с триггером «питание» без поля «детектор», а результат закрытия строгих детекторов — записью действия с перечислением групп

#### Scenario: Старая запись без детектора

- **WHEN** журнал содержит записи, сделанные версией без детекторов
- **THEN** они отображаются без префикса, фильтры и экспорт работают как прежде
