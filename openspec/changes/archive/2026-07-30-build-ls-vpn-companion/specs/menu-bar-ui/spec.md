# menu-bar-ui — Delta Spec

## Purpose

Присутствие приложения в строке меню macOS: иконка, отражающая текущее состояние, и поповер со статусом, баннером, инфо-строками и действиями. Приложение живёт только в меню-баре, без Dock.

## ADDED Requirements

### Requirement: Приложение только в меню-баре

Приложение SHALL работать как меню-бар-приложение (`MenuBarExtra`, window-стиль) без иконки в Dock (`LSUIElement`).

#### Scenario: Запуск приложения

- **WHEN** приложение запущено
- **THEN** в строке меню появляется иконка состояния, в Dock приложение не отображается

### Requirement: Иконка отражает состояние

Иконка строки меню SHALL быть монохромным template-щитом, меняющимся по состоянию: Protected — `checkmark.shield`; Leak — `exclamationmark.shield` с красным акцентом; Offline — `shield.slash`; Paused — `minus.shield` (допустима замена ближайшими SF Symbols).

#### Scenario: Переход в Leak

- **WHEN** состояние сменилось на Leak
- **THEN** иконка меняется на щит с восклицательным знаком и красным акцентом

### Requirement: Состав поповера

Поповер (ширина 340 pt) SHALL содержать сверху вниз: шапку статуса (иконка 26 pt, заголовок «Защищено»/«Утечка»/«Офлайн»/«Пауза», подзаголовок с egress-данными); баннер состояния (зелёный при Protected, красный при Leak — с фактическим составом включённых групп из маппинга); инфо-строки «Проверка» (давность + активный слой детектора), «Группы LS» (выключены / включена «имя»; при Leak — красным), «Сеть» (тип + шлюз); действия «Проверить сейчас», «Пауза мониторинга»/«Возобновить», «Журнал…», «Настройки…»; пункт «Завершить» с шорткатом ⌘Q.

#### Scenario: Поповер при Protected

- **WHEN** пользователь открывает поповер в состоянии Protected
- **THEN** отображается зелёный баннер «Цепочка работает», подзаголовок вида `egress <IP> · warp=on · <colo>` и инфо-строка «Группы LS: выключены»

#### Scenario: Поповер при Leak

- **WHEN** пользователь открывает поповер в состоянии Leak
- **THEN** отображается красный баннер с перечислением заблокированных приложений/групп из фактического маппинга и подзаголовок `egress <IP> — трафик идёт напрямую`

#### Scenario: Проверить сейчас

- **WHEN** пользователь нажимает «Проверить сейчас»
- **THEN** немедленно выполняется свежая проба и UI обновляется по её результату

#### Scenario: Пауза и возобновление из поповера

- **WHEN** пользователь нажимает «Пауза мониторинга»
- **THEN** состояние становится Paused, пункт меняется на «Возобновить»

### Requirement: Соответствие дизайн-системе

Все элементы UI SHALL строиться из компонентов дизайн-системы (токены → атомы → молекулы из §8 SPEC.md): только семантические токены, без хардкод-цветов и размеров во вью; обе темы (светлая и тёмная) через семантические токены; тексты UI — на русском.

#### Scenario: Смена системной темы

- **WHEN** пользователь переключает macOS между светлой и тёмной темой
- **THEN** все окна и поповер корректно отображаются в обеих темах без изменения кода вью
