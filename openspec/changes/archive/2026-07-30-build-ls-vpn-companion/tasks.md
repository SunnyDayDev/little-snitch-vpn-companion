## 5. Helper + XPC

- [x] 5.1 Helper-демон: plist с `BundleProgram`/`MachServices` в `Contents/Library/LaunchDaemons/`, регистрация `SMAppService.daemon`, XPC-listener с тремя операциями (`version`, `listRuleGroups`, `setRuleGroup`)
- [x] 5.2 Валидация XPC-клиента по code-signing requirement (audit token → SecCode); проверить работоспособность с self-signed сертификатом, при необходимости — задокументированный fallback (D6/риски design.md)
      Вместо приватного audit token используется публичный `NSXPCConnection.setCodeSigningRequirement` (macOS 13+). Requirement строится из подписи самого helper: `identifier "…" and certificate leaf = H"<sha1 листового сертификата>"`. При ad-hoc сборке сертификата нет — действует задокументированный fallback (только identifier) с предупреждением в лог.
- [x] 5.3 Вызовы CLI: `rulegroup -e/-d`, `export-model` с выборочным парсингом (имена + enabled), таймаут 3 с; **проверить на месте** коды возврата (повторное включение включённой группы, несуществующее имя) и структуру JSON — зафиксировать в комментариях/README
      Проверено без root 2026-07-29: `export-model` и `rulegroup` без root печатают `littlesnitch must be run as root!` и выходят с кодом **14**.
      Структура `export-model` снята с живой машины 2026-07-30 и закреплена тестами (`Tests/HelperTests/LittleSnitchModelTests.swift`): `groups` — словарь «внутренний id → описание»; имя пользовательской группы в `userProvidedName`, у встроенных имени нет (опознаются по `type`: `builtinMacOSServices`, `builtinICloudServices`); `isActive` есть только у включённых — отсутствие ключа означает «выключена». Проверено на живом LS: список читается как `iCloud Services`, `macOS Services`, `Require VPN Services`.
      Дополнительно найдено (в ТЗ §9 этого нет): Little Snitch имеет **собственный тумблер доступа для CLI** (Настройки → Безопасность); пока он выключен, CLI и под root отвечает `command line tool is not authorized to make changes`. Приложение распознаёт эту ошибку отдельно от отказа helper.
      Коды возврата `rulegroup` для «уже включённой группы» и «несуществующего имени» снимаются на приёмке (сценарии 11–12 §14).
- [x] 5.4 `HelperRuleGroupGateway` (XPC-клиент в приложении): версия helper при старте, деградация при недоступности (флаг, ошибка), кнопка «Переустановить…» в настройках
