# onboarding — дельта

## MODIFIED Requirements

### Requirement: Онбординг при первом запуске

При первом запуске приложение SHALL показывать окно онбординга (560 pt) с тремя карточками-шагами (активен текущий, остальные приглушены; прогресс-точки внизу):

1. «Разрешить привилегированный helper» — кнопка «Установить helper…» (регистрация демона). Карточка SHALL выводиться из состояния helper (см. helper-lifecycle): во время регистрации кнопка неактивна и называет операцию, при ожидании одобрения текст шага содержит строку статуса со ссылкой «Открыть Системные настройки…» и кнопку «Удалить…», при подключённом helper шаг закрыт: номер заменён отметкой выполнения, строка статуса показывает версию, кнопки нет;
2. «Создать rule group в Little Snitch» — ссылка «Открыть Little Snitch…» (группа «VPN down» с deny-правилами создаётся пользователем). Текст шага SHALL предупреждать: в группу включаются только блокируемые приложения; браузер и VPN-клиент включать нельзя — иначе при закрытом трафике (утечка или строгий режим) будет нечем пройти captive portal и поднять VPN;
3. «Разрешить уведомления» — запрос разрешения Notification Center.

#### Scenario: Первый запуск

- **WHEN** приложение запущено впервые
- **THEN** показывается окно онбординга с тремя шагами, активен первый

#### Scenario: Установка helper из онбординга

- **WHEN** пользователь нажимает «Установить helper…»
- **THEN** helper регистрируется через SMAppService, кнопка становится неактивной «Устанавливаем…», приложение ждёт ответа демона; если macOS требует одобрения, раздел Системных настроек открывается один раз, в шаге появляется строка статуса со ссылкой «Открыть Системные настройки…», и активным становится шаг 2

#### Scenario: Helper подключён из онбординга

- **WHEN** после установки или одобрения демон ответил
- **THEN** шаг 1 закрыт: отметка выполнения вместо номера, строка статуса с версией, кнопки нет

#### Scenario: Повторный запуск

- **WHEN** приложение запущено не впервые
- **THEN** онбординг не показывается, приложение сразу работает в меню-баре

#### Scenario: Предупреждение о составе группы

- **WHEN** пользователь находится на шаге создания rule group
- **THEN** текст шага содержит предупреждение не включать браузер и VPN-клиент в группу
