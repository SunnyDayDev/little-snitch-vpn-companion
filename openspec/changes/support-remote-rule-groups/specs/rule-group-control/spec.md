# rule-group-control — дельта

## MODIFIED Requirements

### Requirement: Узкий XPC-контракт

XPC-интерфейс helper SHALL оставаться узким и перечислимым: версия helper; список rule groups (имя + enabled-состояние + вид группы, JSON); включение/выключение rule group по имени; установка failsafe-конфигурации (активность строгого режима, список групп, таймаут супервизии). Произвольные команды SHALL NOT проходить по построению интерфейса.

Список групп SHALL включать группы всех видов, которые Little Snitch показывает в разделе Rule Groups и принимает в `littlesnitch rulegroup -e/-d`: встроенные (`builtin*`), локальные (`userProvidedName`) и подписанные по URL (`loadedFromURL`, имя из `factoryName`; если пользователь переименовал подписку в Little Snitch — её пользовательское имя). Вид группы SHALL передаваться необязательным полем `kind` со значениями `builtin`, `local`, `remote`; запись модели без имени в любом из известных полей SHALL пропускаться без ошибки. Отсутствие `isActive` SHALL трактоваться как «выключена» для группы любого вида.

#### Scenario: Запрос списка групп

- **WHEN** приложение вызывает операцию списка групп
- **THEN** helper выполняет `littlesnitch export-model`, выборочно парсит модель и возвращает только имена, enabled-состояния и вид групп

#### Scenario: Подписанная группа в списке

- **WHEN** в модели есть запись с `type: loadedFromURL`, `factoryName: "Require VPN Services"` и без `isActive`
- **THEN** список содержит группу «Require VPN Services» с состоянием «выключена» и видом `remote`

#### Scenario: Переименованная подписка

- **WHEN** пользователь переименовал подписку в Little Snitch, и модель хранит для неё и имя из файла, и пользовательское имя
- **THEN** список содержит группу под пользовательским именем — тем, которое показывает Little Snitch и принимает `rulegroup -e/-d`

#### Scenario: Локальная группа с типом

- **WHEN** у локальной группы в модели есть `userProvidedName` и любое значение `type` (в том числе `loadedFromFile` или отсутствие ключа)
- **THEN** группа попадает в список под `userProvidedName` с видом `local`

#### Scenario: Безымянная запись пропускается

- **WHEN** запись модели не содержит имени ни в `userProvidedName`, ни в `customName`, ни в `factoryName`, а её `type` не является известным встроенным
- **THEN** запись не попадает в список, остальные группы возвращаются без ошибки

#### Scenario: Ответ без поля вида

- **WHEN** JSON списка групп не содержит поля `kind` или содержит незнакомое значение
- **THEN** приложение читает список без ошибки, вид группы считается неизвестным и в интерфейсе не подписывается

#### Scenario: Запрос версии

- **WHEN** приложение вызывает операцию версии
- **THEN** helper возвращает строку версии для отображения в UI

#### Scenario: Передача failsafe-конфигурации

- **WHEN** пользователь включает строгий режим или меняет список управляемых групп
- **THEN** приложение передаёт helper актуальную failsafe-конфигурацию одной операцией XPC

### Requirement: Список групп в настройках

Приложение SHALL получать список rule groups (имя + текущее состояние + вид) через helper и отображать в настройках с чекбоксом «включать при утечке» у каждой. Подписанные группы SHALL помечаться подписью «подписка» рядом с состоянием в LS. Список SHALL обновляться при открытии вкладки и по кнопке «Обновить список из LS». Если helper вернул несколько групп с одним именем, приложение SHALL показать одну строку и записать в журнал предупреждение с этим именем: различить такие группы при включении по имени невозможно.

#### Scenario: Открытие вкладки Группы

- **WHEN** пользователь открывает вкладку «Группы» в настройках
- **THEN** приложение запрашивает у helper актуальный список групп и отображает его с чекбоксами

#### Scenario: Подписка во вкладке

- **WHEN** список содержит группу вида `remote`, включённую в LS
- **THEN** её строка показывает подпись «подписка · включена в LS», а чекбокс «включать при утечке» работает так же, как у локальной группы

#### Scenario: Одноимённые группы

- **WHEN** список от helper содержит локальную группу и подписку с одинаковым именем
- **THEN** во вкладке показана одна строка с этим именем, в журнал записано предупреждение об одноимённых группах, reconcile продолжает работать по имени

#### Scenario: Несуществующее имя группы в маппинге

- **WHEN** reconcile пытается включить группу, имени которой нет в LS
- **THEN** в журнал пишется внятная ошибка, отправляется уведомление, приложение не падает
